# SoundDraft

Mac-first local desktop studio for authors who dictate first drafts. Authors bring an OpenRouter API key. Prerecorded audio is the primary workflow, with local microphone recording included. No account system or telemetry.

Preserve the raw original transcript. AI Formatting & Artifact Removal is optional and must produce visible changes that can be accepted, rejected or undone. Never present the feature as creative rewriting or general AI assistance. Transcript-only mode disables formatting, not cloud transcription.

Keep manuscripts central, with graphite navigation, ivory reading surfaces, restrained sage approvals and amber removals. Native-feeling, keyboard-accessible, comfortable for long desktop sessions. Night appearance and text scaling matter.

First release: projects, imports, recording, resumable transcription, review, text editing, export, local metrics and CSV. Defer live transcription, waveform editing, cloud collaboration and spreadsheet API sync.
